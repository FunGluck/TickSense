## Интерпретация и ограничения

Онлайн, чанки, сущности и block entities действительно меняются. Однако типы сущностей, конкретные блочные объекты, маршруты и вклад каждого мира отдельно не размечены и не сверены независимым счётчиком. Это подтверждение изменяемости агрегатов, не точности всех подсчётов. В частности, последовательность block entities на 1.21.8 — 0→1→0→1; уменьшение не считается неисправностью.

MSPT и TPS изменяются во всех файлах. У 1.21.1 на строках 11→12 MSPT 1,871→47,691 мс, TPS 20,044→19,187 и онлайн 0→1; одновременность не доказывает, что замедление вызвано игроком или чанками. Случаи TPS немного выше 20 (максимум 20,237 на 1.21.4) сохранены как значения Paper без дополнительного ограничения — не признаны повреждением CSV. Интервал между снимками не обязан составлять ровно 10 секунд, поскольку scheduler работает в серверных тиках.

Время журнала локальное (UTC+05:00), CSV — UTC: игровым записям 03.11 местного времени соответствуют файлы за 02.11 UTC. Переход UTC-дня не проверен. Два сброса elapsed_ms согласованы с журналами; сам по себе этот признак не умеет обнаружить любой возможный перезапуск в обрезанной выборке.

## Python и найденная проблема теста

Для каждого исходного CSV выполнены неизменённые load_data → engineer_features → статистический детектор → predict Isolation Forest → JSON/HTML. Затем проверен реальный analyze.py TRAIN TEST --json ... --html ... --no-show: все четыре завершились успешно, число строк/сессий сохранилось. Обучение выполнялось на отдельном существующем datasets/metrics-2026-10-31.csv, не на игровых CSV. Это проверка обработки, не качества ML. Локальные выходы и детальный протокол — .gradle/gameplay-audit/ (не включаются в Git).

Полный Python suite: **44 теста, 43 PASS, 1 FAIL**. FAIL: analysis.test_html_report.HtmlReportTest.test_navigator_and_typography, строка 141. Тест ищет буквальную минифицированную строку `16px/1.65 Inter,"Segoe UI",Arial,sans-serif`. Существующий пользовательский CSS содержит те же значения с пробелами (style.css:19). Это хрупкость строковой проверки после форматирования CSS, не найденная ошибка алгоритмов/телеметрии. Предлагаемое исправление после согласования: сравнивать нормализованное CSS-значение или разобранные свойства; не возвращать пользовательский CSS в минифицированный вид. Код/тест не исправлялись по ограничению задачи. Дополнительно 6/6 тестов compatibility harness прошли.

Изменения исходных CSV исключены проверкой SHA-256 до/после чтения. Пользовательский CSS, Java, ML, CSV-схема и Pilot JAR не изменялись. Серверы не запускались, миры и журналы не менялись.
