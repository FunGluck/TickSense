# Валидация TickSense перед ограниченным Pilot

Срез 03.11.2026. Это сводка выполненных проверок, а не обещание production-безопасности или низких накладных расходов.

## Совместимость одного JAR

Экспериментальный `TickSense-0.8.1-compat-test.jar`, Java 21 (Temurin 21.0.10+7), API baseline 1.21.1. SHA-256: `de27c5a0299f575e86ffe90606b9d1bfc3783bf079c62f06ff8e07e590a07eb5`.

| Paper | Build | Загрузка / CSV / повторный запуск | Игровые метрики |
|---|---:|---|---|
| 1.21.1 | 133 | PASS | Менялись онлайн, чанки, сущности, block entities и MSPT |
| 1.21.4 | 232 | PASS | То же |
| 1.21.8 | 60 | PASS | То же; CSV-снимок после выхода игрока отсутствует |
| 1.21.11 | 132 | PASS | То же |

Подтверждены четыре конкретные сборки, не все Paper 1.21.x. Реакция счётчиков на игру не является независимой сверкой абсолютных количеств. Вход 0→1 наблюдался на всех четырёх версиях, выход 1→0 в CSV — кроме 1.21.8. Folia и другие версии не проверены. Подробности функциональных испытаний: [совместимость](compatibility.md).

## Функциональные проверки

Java-тесты проверяют 12 полей CSV, сериализацию/UTF-8, недоступные GC-счётчики, ограниченную очередь, переполнение, создание/повторное открытие/ротацию и ошибки файлов. Автоматическая UTC-ротация проверена модульно; реальный переход UTC-дня на сервере не проверен.

Python-тесты покрывают сессии, признаки без утечки будущих значений, статистику и Isolation Forest, сравнение моделей, пороговые эпизоды/объяснения, совместимость v1/v2, JSON, автономный HTML, безопасность встраивания и интерактивную навигацию. Игровые CSV всех четырёх версий обработаны анализатором. Исправлена хрупкая проверка CSS без изменения его требуемых значений.

## Что установлено о накладных расходах

- Phase 1: один завершённый A/B/B/A на пустом сервере. Результаты не устанавливают точные расходы; различие памяти нельзя называть оптимизацией TickSense.
- Phase 2: A1/B1 прошли, B2 получил watchdog с тиком около 13,3 с; снимок серверного потока показывает SetEndOfFile при сохранении данных мира Paper. A2 — отдельный диагностический контроль. Первопричина не установлена; косвенное влияние TickSense не исключено.
- Последний финальный блок не завершён: B1 остановлен ошибкой наблюдателя Nonmonotonic sampling после паузы и некорректных догоняющих замеров. Ошибка harness исправлялась и тестировалась; это не доказательство ошибки плагина. Полного чистого повторного блока недостаточно для заключения.

**Низкие накладные расходы не доказаны.** Готовность по влиянию на производительность: INSUFFICIENT EVIDENCE. Для добровольного Pilot необходимы экспериментальный статус, согласование условий, резервная копия и возможность отключения. Длительная работа, аппаратно-независимый бюджет влияния и production-готовность не подтверждены.

Временные benchmark-harness, их специализированные тесты и подробные инструкции расследований удалены из исходного проекта. Первичные данные и окружения остаются в отдельном локальном архиве TickSense-Compatibility; он не изменялся и не публикуется. Краткая общая [методика сравнения](overhead-methodology.md) сохранена, дальнейшие эксперименты не запускаются автоматически.
