После изменений: см. analysis/README.md. Отдельные компоненты детекции и параметры ML не переписаны. Java и релизные артефакты не менялись.

Проверка синтетических 24 часов на рабочем компьютере: 8640 строк, загрузка, признаки, обучение, предсказание, JSON и HTML — 3,18 с с включённым tracemalloc; пик отслеживаемых выделений Python 8,52 MiB. Это не полная память процесса и не серверный benchmark. Визуальная проверка браузера не проводилась; JavaScript проверяется node --check и существующими тестами навигации.
