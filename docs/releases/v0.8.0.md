# TickSense v0.8.0 — Pilot

Черновик описания первого ограниченного тестового выпуска. Публикация GitHub Release выполняется отдельно владельцем проекта. Это экспериментальный Pilot, не стабильный релиз.

## Для администратора сервера

Вам нужен только **`TickSense-0.8.0-pilot.jar`** из файлов официального [GitHub Release](https://github.com/fungluck/TickSense/releases) после его публикации. Архивы исходников скачивать не нужно. Требования: **Paper 1.21.4**, **Java 21**, свободное место на диске и возможность перезапустить сервер.

1. Сделайте резервную копию и установите JAR в `plugins` на остановленном сервере.
2. Запустите сервер, проверьте появление и рост CSV в `plugins/TickSense/data/`.
3. Оставьте плагин работать на согласованный срок.
4. Передайте выбранные завершённые CSV разработчику согласованным способом.
5. Получите от разработчика готовый HTML-отчёт и откройте его в браузере.

**Python, исходники и самостоятельное создание отчёта администратору не нужны.** Анализ выполняет разработчик. Плагин не отправляет файлы автоматически; вы контролируете передачу данных.

[Пошаговая инструкция, проверка запуска и удаление](../pilot-guide.md).

## Что входит

- Локальный сбор показателей работы сервера: TPS, MSPT, игроки онлайн, память, чанки, сущности и GC.
- Отдельный анализ разработчиком с графиками, пороговыми и ML-сигналами и пояснениями на основе измерений.
- Русскоязычный HTML, работающий без интернета: выбор сессии, масштабирование и обзорный график над MSPT.
- Защита от дописывания к CSV с незавершённой строкой после аварии.

Накладные расходы пока не измерены. Причины лагов автоматически не устанавливаются. При переполнении очереди, ошибке диска или аварийной остановке возможны потери измерений. Начните с тестовой копии сервера. [Аудит и оставшиеся проверки](../pilot-audit.md).

## Для сопровождающего выпуск

Версия внутри JAR — `0.8.0-pilot`, предполагаемый тег выпуска — `v0.8.0`. Локальный артефакт: `build/libs/TickSense-0.8.0-pilot.jar`.

SHA-256 подготовленного локально JAR:

```text
2abc8cde1d49e9072708a402dbd028cdb83a71e7b53c89894dafce6c82628743
```

Перед публикацией повторно проверьте, что прикладываемый JAR соответствует этой сумме; если пересобранный файл отличается, обновите сумму. Полные локальные сведения — в `build/pilot-artifact.json` и `.jar.sha256` рядом с JAR. Не прикладывайте приватные серверные CSV/HTML к публичному выпуску без отдельного разрешения владельца данных. Анализ и его зависимости описаны в [инструкции разработчика](../../analysis/README.md).
