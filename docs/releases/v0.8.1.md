# TickSense v0.8.1 — Compatibility Pilot

**Experimental / Pre-release.** Ограниченное добровольное тестирование, не стабильный production-релиз.

## Что такое TickSense

Лёгкий экспериментальный сборщик метрик производительности Minecraft Paper. Плагин записывает телеметрию в локальный CSV; отдельный Python-анализатор формирует автономный HTML-отчёт с графиками и пояснениями. Для участия администратору нужен только готовый JAR. Python и анализатор устанавливать на игровой сервер не требуется.

## Проверенная совместимость

| Paper | Build |
|---|---|
| 1.21.1 | 133 |
| 1.21.4 | 232 |
| 1.21.8 | 60 |
| 1.21.11 | 132 |

Требуется **Java 21**. Проверены конкретные сборки, не все версии Paper 1.21.x. Folia не проверена.

Результаты последующих испытаний этого JAR на Paper 26.x под Java 25 приведены в отдельной матрице. [Совместимость Minecraft 26.x](../minecraft-26x.md).

## Установка

1. Штатно остановите сервер и сохраните резервную копию.
2. Скачайте **TickSense-0.8.1-pilot.jar** из Assets этого выпуска.
3. Поместите файл в `plugins/`, убрав предыдущий JAR TickSense из этой папки.
4. Запустите сервер; не используйте `/reload` вместо нормального перезапуска.
5. Проверьте появление и увеличение CSV в `plugins/TickSense/data/`.

Файлы называются `metrics-v2-YYYY-MM-DD.csv`, дата — UTC. Интервал остаётся 200 серверных тиков: при лагах это может быть дольше 10 секунд реального времени.

## Особенности и изменения

- Локальное хранение телеметрии и отсутствие автоматической отправки данных. Администратор сам выбирает CSV для передачи разработчику.
- Автономный анализ CSV и HTML-отчёты с графиками; исходный код открыт на GitHub.
- Paper API baseline 1.21.1 при сохранении Java 21 и прежней функциональности коллектора.
- Совместимость проверена на четырёх сборках Paper; пользовательская документация актуализирована.

При подготовке этой версии Java-код, CSV v2, настройки и механизм bounded asynchronous writer не изменялись. Все 6 class-файлов, config.yml и manifest побайтово совпали с проверенным `0.8.1-compat-test`; в plugin.yml изменена только версия на `0.8.1-pilot`. Новые Minecraft-тесты не проводились.

## Ограничения

- Низкие накладные расходы **не доказаны**. Предыдущие опыты содержали неизвестную задержку Paper при сохранении мира и неполные выборки наблюдателя; последний полный блок не завершён.
- Длительная стабильность на реальных загруженных серверах не подтверждена.
- Отчёт не определяет причины лагов автоматически; совпадение сигналов не доказывает ухудшение игрового опыта.
- Рекомендуется сначала тестовая копия сервера с резервной копией мира и возможностью быстро отключить плагин.
