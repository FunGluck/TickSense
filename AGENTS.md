# Правила TickSense

- Java 21, Paper API 1.21.4, Gradle Kotlin DSL. Код проекта находится в корне.
- Сохранять небольшие классы с конкретной ответственностью; не добавлять ML, backend или команды без отдельной задачи.
- Получать серверные метрики только в синхронном scheduler. Файловые операции и конфигурацию обрабатывать в потоке записи.
- Между потоками передавать immutable snapshots через ограниченную очередь; главный поток не ждёт свободного места.
- UTC определяет дату файла; elapsed_ms использует System.nanoTime(). Не собирать данные об отдельных игроках.
- Проверять изменения через ./gradlew test build. Не создавать и не запускать Minecraft-сервер без явного запроса.
- Обновлять документацию при изменении формата CSV или конфигурации.
