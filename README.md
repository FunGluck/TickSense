# TickSense

Локальный сборщик метрик для Paper 1.21.4, Java 21. Не содержит ML и не отправляет данные по сети.

## Сборка

Нужны JDK 21 и доступ к Maven Central, репозиторию Paper и дистрибутиву Gradle при первой сборке.

```powershell
.\gradlew.bat clean test build
```

Linux/macOS: `sh ./gradlew clean test build`.
Результат: `build/libs/TickSense-0.1.0.jar`.

## Установка

1. Скопируйте JAR в `plugins/` существующего Paper 1.21.4 сервера с Java 21.
2. Запустите сервер. Плагин создаст `plugins/TickSense/config.yml` в фоновом потоке.
3. CSV появится после первого интервала в `plugins/TickSense/data/metrics-YYYY-MM-DD.csv`.
4. Для изменения конфигурации остановите сервер, измените YAML и запустите его снова.

Параметры по умолчанию:

```yaml
collection:
  enabled: true
  interval-ticks: 200
storage:
  directory: data
  queue-capacity: 1024
```

Интервал и ёмкость должны быть положительными. Каталог задаётся внутри папки плагина. При ошибке конфигурации или записи сбор прекращается с сообщением SEVERE; для возобновления устраните причину и перезапустите сервер. `enabled: false` отключает сбор.

При заполнении очереди новый снимок отбрасывается, предупреждения агрегируются раз в 30 секунд и при завершении. При штатном отключении сбор прекращается и поток записи получает до 3 секунд на опустошение очереди. Каждая строка сбрасывается в файловый буфер ОС; принудительное завершение процесса или сбой питания могут привести к потере данных. Автоматическое исправление повреждённых CSV не реализовано.

Тесты обычных Java-компонентов проверяют CSV, повторное открытие, UTC-ротацию и переполнение очереди. Интеграционная проверка в Minecraft в рамках этой задачи не выполняется.

Описание измерений: [docs/metrics.md](docs/metrics.md).

## Python-анализ

В `analysis/` подготовлена заготовка будущего анализатора с зависимостями pandas и matplotlib. Сейчас она только принимает путь к CSV через командную строку; загрузка данных, графики и ML не реализованы. Инструкция настройки окружения и запуска: [analysis/README.md](analysis/README.md). Локальные данные храните в `datasets/`, содержимое которого исключено из Git.
